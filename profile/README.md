## Drop2Run

Drag a folder or a `.zip`, get an HTTPS link in about 15 seconds.
No git, no build step, no repository.

- **[dropto.run](https://dropto.run)** — the platform
- **[drop2run-cli](https://github.com/Drop-to-run/drop2run-cli)** — the CLI and the MCP server, so an agent can publish what it just wrote
- **[Docs](https://dropto.run/docs)**

```bash
npm i -g drop2run
drop2run login
drop2run deploy dist
```
